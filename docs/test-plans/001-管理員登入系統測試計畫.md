## 3. 測試案例明細

### F01 / F02 — Router 路由守衛

```typescript
// frontend/src/__tests__/router.spec.ts
describe('路由守衛', () => {
  it('未登入使用者造訪 /，應強制跳轉 /login')
  it('已登入使用者造訪 /login，應強制跳轉 /')
  it('auth.loading 為 true 時，應等待初始化完成再判斷')
})
```

### F31 — LoginForm 元件

```typescript
// frontend/src/__tests__/LoginForm.spec.ts
describe('登入表單', () => {
  it('渲染帳號、密碼輸入欄位與登入按鈕')
  it('帳號密碼為必填欄位（HTML5 required）')
  it('輸入帳密後點擊登入，emit submit 事件帶有 username/password')
  it('登入失敗時顯示錯誤訊息（由 prop 傳入）')
  it('空白帳號或密碼時按鈕 disabled')
})
```

### F08 — AppHeader

```typescript
// frontend/src/__tests__/AppHeader.spec.ts
describe('頂部導航列', () => {
  it('已登入時顯示登出按鈕')
  it('點擊登出按鈕，emit logout 事件')
  it('顯示目前登入的使用者名稱')
})
```

### F19-F22 — Auth Store

```typescript
// frontend/src/__tests__/authStore.spec.ts
describe('Pinia Auth Store', () => {
  it('init() 呼叫 /api/v1/session 並設定 authenticated')
  it('init() 失敗時 authenticated = false')
  it('login() 成功回傳 null，authenticated = true')
  it('login() 失敗回傳 error message')
  it('logout() 清除 username 與 authenticated')
  it('session 過期後 API 回 401，前端應能偵測')
})
```

### F10 / F36 — 後端 Session 測試

```go
// src/internal/handler/handler_test.go 擴充
func TestSession_Expired(t *testing.T) {
    // 1. 登入取得 cookie
    // 2. 手動將 session MaxAge 設為 -1（模擬過期）
    // 3. 呼叫 GET /api/v1/services → 預期 401
}

func TestSession_MultipleLogins(t *testing.T) {
    // 1. 管理員 A 登入取得 cookie_a
    // 2. 管理員 B 使用相同帳號登入取得 cookie_b
    // 3. 使用 cookie_a 呼叫 API → 仍為 200（session 獨立）
    // 4. 使用 cookie_b 呼叫 API → 仍為 200
}
```
