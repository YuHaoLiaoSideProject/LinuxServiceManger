## 3. 測試案例明細

### F11 / F12 — 環境變數啟動檢查

```go
// src/internal/auth/auth_test.go
func TestHasDefaultSecret(t *testing.T) {
    tests := []struct {
        name        string
        sessionKey  string
        adminPass   string
        wantDefault bool // true = 使用預設值，應觸發 Fatal
    }{
        {"both set",       "my-secret-key-32bytes!!", "strong-pass", false},
        {"missing key",    "",                         "strong-pass", true},
        {"missing pass",   "my-secret-key",            "",           true},
        {"both missing",   "",                         "",           true},
        {"blank key",      "   ",                      "strong-pass", true},  // #8
        {"blank pass",     "my-key",                   "   ",        true},  // #8
        {"both blank",     "",                         "",           true},  // #8
    }

    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            t.Setenv("SESSION_KEY", tt.sessionKey)
            t.Setenv("ADMIN_PASS", tt.adminPass)

            got := auth.HasDefaultSecret()
            if got != tt.wantDefault {
                t.Errorf("HasDefaultSecret() = %v, want %v", got, tt.wantDefault)
            }
        })
    }
}
```

### F13-F17 — 服務鎖定邏輯

```go
// src/internal/systemd/systemd_test.go
func TestIsLocked(t *testing.T) {
    tests := []struct {
        name          string
        unitFileState string
        fragmentPath  string
        unlockedEnv   string   // UNLOCKED_SERVICES 環境變數值
        want          bool
        desc          string
    }{
        // 正常解鎖（全部條件滿足）
        {"nginx.service", "enabled", "/etc/systemd/system/nginx.service", "", false,
            "FragmentPath=/etc + not dbus- + enabled → unlocked"},

        // FragmentPath 不在 /etc/systemd/system/（#13）
        {"sshd.service", "enabled", "/usr/lib/systemd/system/sshd.service", "", true,
            "FragmentPath=/usr/lib → locked"},
        {"dbus.service", "enabled", "/run/systemd/system/dbus.service", "", true,
            "FragmentPath=/run → locked"},

        // dbus- 前綴（#14）
        {"dbus-org.freedesktop.service", "enabled", "/etc/systemd/system/dbus-org.freedesktop.service", "", true,
            "dbus- prefix → locked even with /etc FragmentPath"},
        {"dbus-org.foo.service", "enabled", "/etc/systemd/system/dbus-org.foo.service", "", true,
            "dbus- prefix → locked"},

        // UnitFileState 限制（#15）
        {"some.service", "static", "/etc/systemd/system/some.service", "", true,
            "static → locked"},
        {"some.service", "masked", "/etc/systemd/system/some.service", "", true,
            "masked → locked"},
        {"some.service", "alias", "/etc/systemd/system/some.service", "", true,
            "alias → locked"},
        {"some.service", "indirect", "/etc/systemd/system/some.service", "", false,
            "indirect → unlocked (not in blacklist)"},

        // UNLOCKED_SERVICES 強制解鎖（#16）
        {"nginx.service", "enabled", "/usr/lib/systemd/system/nginx.service", "nginx", false,
            "UNLOCKED_SERVICES=nginx overrides FragmentPath check"},
        {"myapp.service", "static", "/etc/systemd/system/myapp.service", "myapp", false,
            "UNLOCKED_SERVICES=myapp overrides static check"},
        {"dbus-test.service", "enabled", "/etc/systemd/system/dbus-test.service", "dbus-test", false,
            "UNLOCKED_SERVICES=dbus-test overrides dbus- check"},

        // UNLOCKED_SERVICES glob 模式（#17）
        {"myapp.service", "enabled", "/usr/lib/systemd/system/myapp.service", "my-*", false,
            "glob my-* matches myapp"},
        {"myapp.service", "enabled", "/usr/lib/systemd/system/myapp.service", "my*", false,
            "glob my* matches myapp"},
        {"nginx.service", "enabled", "/usr/lib/systemd/system/nginx.service", "my-*", true,
            "glob my-* does NOT match nginx → remains locked"},
        {"dev-api.service", "enabled", "/usr/lib/systemd/system/dev-api.service", "dev-*", false,
            "glob dev-* matches dev-api"},
    }

    for _, tt := range tests {
        t.Run(tt.desc, func(t *testing.T) {
            t.Setenv("UNLOCKED_SERVICES", tt.unlockedEnv)
            got := isLocked(tt.name, tt.unitFileState, tt.fragmentPath)
            if got != tt.want {
                t.Errorf("isLocked(%q, %q, %q) = %v, want %v (%s)",
                    tt.name, tt.unitFileState, tt.fragmentPath, got, tt.want, tt.desc)
            }
        })
    }
}
```

### F18 — API 錯誤不洩漏內部細節

```go
// handler_test.go 擴充
func TestErrorResponse_NoInternalDetails(t *testing.T) {
    // 場景 1：D-Bus 連線失敗 → 回應只含 "failed to list services"
    // 場景 2：權限不足 → 回應只含 "failed to start {name}"
    // 場景 3：服務不存在 → 回應只含 generic error

    forbiddenWords := []string{
        "stack trace", "panic", "goroutine",
        "/usr/lib/", "/etc/systemd/", "/home/",
        "dbus", "permission denied", "connection refused",
        "0x", "runtime error",
    }

    // 每個錯誤回應都要檢查不含以上關鍵字
    for _, word := range forbiddenWords {
        if strings.Contains(body, word) {
            t.Errorf("error response leaked internal detail: %q", word)
        }
    }
}
```

## 6. 風險與備註

| 項目 | 說明 |
|------|------|
| `t.Setenv()` | Go 1.22+ 支援，確保測試間環境變數不互相汙染 |
| `isLocked()` | 為 `systemd.go` 中的私有函數，測試檔案需使用 `package systemd`（白箱測試） |
| 啟動流程測試 | `main.go` 中的 `log.Fatal` 無法在單元測試中直接驗證（會終止 process），透過 `auth.HasDefaultSecret()` 單元測試間接驗證 |
| `UNLOCKED_SERVICES` glob | `filepath.Match` 的行為已在 Go stdlib 測試中覆蓋，本測試聚焦於整合到 `isLocked()` 的正確性 |
