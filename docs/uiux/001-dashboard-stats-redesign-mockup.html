📊 Dashboard 統計卡片 — 升級為狀態過濾

Linux Service Manager · StatsBar 與 status pills 功能合併（比較稿，可切換主題／裝置，AFTER 面板可直接點擊試玩）

0️⃣ 問題總覽 — 同一份資訊，兩個元件

Dashboard 頂部同時有「不可點的統計卡片」與「可點的狀態 pills」，呈現同一份狀態統計；且兩者的計數口徑不一致（卡片跟 tab、pills 不看 tab；卡片 running 用 active family、pills 用 sub==='running'），造成「數字 ≠ 點擊後的列數」。

問題實測依據（code）影響
功能重複卡片：總服務數/執行中/失敗（StatsBar.vue）≈ pills：全部/執行中/失敗/未啟用（Toolbar.vue）同一資訊兩次呈現；「未啟用」只有 pills 有
計數不看 tab卡片用 statsServices（tab-filtered）；pills 用 filterCounts（全部 services）「我的服務」tab 下，pills 13 ≠ 表格 8 列
running 定義不同卡片：active∈{active,running,activating,deactivating,reloading}；filter：sub==='running'點 pills 後列數 ≠ 卡片數字
emoji 圖示📋✅❌（跨平台渲染不一致，011 已確立改 SVG 原則）視覺品質

結論：把「統計」與「過濾」合成一件事 — 卡片即 filter。四張卡片（全部／執行中／失敗／未啟用）構成完整狀態篩選，Toolbar 移除 pills；計數統一為 tab-filtered 且與 filter 述詞一致，讓「卡片數字 = 點擊後的列數」成立。

2️⃣ 元件解剖 — 狀態過濾卡片

沿用現況 stat-card 骨架，改為 <button>（原生 focus / Enter / Space 支援），新增 active 態與第 4 張「未啟用」卡。

Idle 狀態 預設

高度 內容自然高（icon 20px + padding） ・ 圓角 10px（--lms-radius）・ 左邊線 4px ・ 卡片間距 0.6rem ・ 內距 0.6rem / 1rem
value 1.3rem/700 ・ label 0.75rem muted ・ icon 20px

Active 狀態 filter 生效

邊框 accent（--lms-accent）・ 底 accent-light（--lms-accent-light）・ 左邊線保留狀態色 4px success
label 轉 accent ・ aria-pressed="true" ・ hover 上浮 2px + shadow（尊重 reduced-motion）
focus-visible 2px accent outline + 2px offset（WCAG 2.4.7）

3️⃣ 狀態與互動矩陣（stat card）

每張卡片都是 <button>，行為與現有 pills 一致（radio 群組、再點一次取消）。

狀態視覺互動
預設 Idlesurface 底・border・狀態色左邊線可點擊（cursor:pointer）
Hover上浮 2px・shadow・邊框 accent單擊觸發 filter
Focus-visible2px accent outline + 2px offset鍵盤 Enter / Space 觸發（button 原生）
Active（filter on）accent 邊框・accent-light 底・aria-pressed=true再點一次 → 回到「全部」
Disabled（loading）50% opacity・not-allowed不觸發；保留既有 filter（與現況 pills 相同）
空結果（0 筆）數字顯示 0，卡片仍可點表格區顯示 EmptyState + 「清除條件」一鍵重置
無障礙：卡片群組 role="group" + aria-label="狀態過濾"；狀態不只靠顏色（卡片有文字標籤 + 數字，符合 WCAG 1.4.1）；觸控目標 mobile 卡片高 78px 遠超 40px（2.5.5）；圖示皆 aria-hidden="true"。
