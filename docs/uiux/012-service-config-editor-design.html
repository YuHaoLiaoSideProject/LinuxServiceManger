6️⃣ ServiceRow 進入點 — 現況 vs 新增（實測數據）

Actions 欄現況 29%：3 顆文字按鈕單列 32px。新增第 4 顆後，文字按鈕在任何常見桌面寬度皆爆版（實測：維持 3 欄 grid → 換行成 2 列 69px，違反 BDD「同列」；改 4 欄 grid → 按鈕壓縮至 86px 文字裁切、@1025px overflow）。
決策：Edit/View Config 採 icon-only 36px（鉛筆／眼睛 SVG）＋tooltip＋aria-label；Actions 欄寬 29%→33%（自 Sub 9%→7%、AutoStart 15%→13% 調整）。
