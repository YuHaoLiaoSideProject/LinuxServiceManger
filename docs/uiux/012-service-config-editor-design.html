2. 完整畫面 — 桌面 Modal（≥768px）／ 手機全頁（≤767px）

同一份編輯內容（ConfigEditorContent：標題／路徑／驗證橫幅／CodeMirror／footer）由兩個 shell 共用：ConfigEditorModal（桌面，Dashboard 背景 dim 保留）與 ConfigEditorView（手機全頁 route）。 互動：切換上方「Desktop／Mobile」；點 Dashboard 的鉛筆按鈕 → 桌面開 Modal、手機模擬導航到全頁。桌面 Modal 支援 Esc／backdrop／✕ 關閉、focus trap、背景捲動鎖定。編輯器可點擊直接輸入，內容變更即 dirty。

6. ServiceRow 進入點 — 現況 vs 新增（實測數據）

Actions 欄現況 29%：3 顆文字按鈕單列 32px。新增第 4 顆後，文字按鈕在任何常見桌面寬度皆爆版（實測：維持 3 欄 grid → 換行成 2 列 69px；改 4 欄 grid → 按鈕壓縮至 86px 文字裁切、@1025px overflow）。
決策：Edit/View Config 採 icon-only 36px（鉛筆／眼睛 SVG）＋tooltip＋aria-label；Actions 欄寬 29%→33%（自 Sub 9%→7%、AutoStart 15%→13% 調整）。
