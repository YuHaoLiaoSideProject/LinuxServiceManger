6️⃣ 狀態矩陣

完整涵蓋 idle／hover／focus／disabled／loading／error／空結果。

狀態視覺互動
ChannelCard · Idle（啟用）正常卡片、toggle ON 綠測試／編輯／刪除可用；toggle 可點
Hover / Focus卡片 shadow 提升；動作按鈕 accent；focus ring 3px按鈕可點
停用（enabled=false）卡片 opacity:0.55 ＋ 「停用」標籤toggle OFF；測試／編輯仍可用；刪除可用
自動停用（failures≥10）黃色橫幅「已自動停用：{原因}」「重新啟用」→ PATCH enabled=true（failures 歸零、橫幅消失）
測試中測試按鈕 spinner ＋ 卡片動作鎖定其餘動作 disabled；完成恢復
刪除確認ConfirmModal「確定刪除 Channel「XXX」？此操作無法復原。」確認 → DELETE ＋ 卡片淡出；取消 → 關閉
表單 · 必填錯誤欄位紅框 ＋ 「請填寫必要欄位」前端攔截不發 API
表單 · 事件未勾選事件區紅框 ＋「至少需勾選一個觸發事件」前端攔截
表單 · Saving儲存按鈕 spinner ＋ disabled不可重複送出
表單 · 儲存失敗Toast 錯誤原因表單內容保留供修正
上限 20Toast「Channel 數量已達上限」新增被攔截
發送紀錄 · 空結果「尚無通知發送紀錄」—
發送紀錄 · 失敗列紅 badge「失敗」＋ mono 錯誤訊息title 顯示全文
