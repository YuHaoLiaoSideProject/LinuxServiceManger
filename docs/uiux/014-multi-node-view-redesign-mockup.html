多機管理 — 節點切換模式設計規格

功能 014 UIUX · 2025-08-25 定案 · 涵蓋 Aggregate Dashboard、單節點切換、離線反應、空狀態

1. Aggregate Dashboard（總覽）

登入後預設進入。頂部統計列顯示全場節點與服務摘要；中間為節點卡片網格，每張卡片可點擊進入該節點的單機視圖。
https://lms.local/dashboard
Linux Service Manager 儀表板 節點管理 稽核日誌
節點 4　3 線上　1 離線 服務 128　119 執行中　2 失敗

2. 單節點視圖（點卡片後）

點擊任一線上節點卡片後進入。URL 變為 ?node={id}。Header 顯示目前節點名稱 + 節點下拉切換選單 + 「所有節點」返回鈕。服務列表僅顯示該節點的服務，操作按鈕完整可用。
https://lms.local/dashboard?node=web-01
Linux Service Manager 儀表板 稽核日誌
目前節點：web-server-01
僅顯示 web-server-01 的 40 個服務
服務狀態開機啟動操作
nginx.service執行中enabled
docker.service執行中enabled
fail2ban.service失敗enabled

3. 離線節點反應

心跳中斷超過 30 秒後，節點卡片自動變為離線態。若管理員正在該節點的單機視圖中，服務列表操作按鈕全部禁用，頂部顯示黃色 Banner。
https://lms.local/dashboard?node=bk-01
Linux Service Manager 儀表板
目前節點：backup-server-01
節點已離線，操作不可用。最後心跳：2 分鐘前。
服務狀態開機啟動操作
nginx.service執行中enabled
sshd.service執行中enabled

4. 空狀態（尚無已註冊節點）

首次登入或所有節點已移除時顯示。引導使用者前往 Node Management 頁面新增節點。
https://lms.local/dashboard
Linux Service Manager 儀表板 節點管理
節點 0 服務 0
📦
尚無已註冊節點
請先前往「節點管理」新增一台機器，或在目標機器上部署 Agent。
