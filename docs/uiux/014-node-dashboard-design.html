Banner：--lms-warning-light 底 + warning 字 + 1px warning 邊框 · radius 6px · role="alert"（節點離線時顯示）
禁用操作：opacity .4 + cursor:not-allowed；離線時 canOperate=false 全部 disabled
僅影響操作：LogDrawer 仍可看快取；狀態以 WS 推送更新
狀態視覺互動
節點在線正常佈局（與單機一致）全部操作可用；Header 顯示節點名 + 綠點
節點離線頂部黃色 Banner「⚠ 節點已離線，操作不可用」+ 操作按鈕全部 disabled不可操作；LogDrawer 可看快取；返回/切換節點可用
操作進行中按鈕 spinner + disabled（in-flight）同節點同服務不可並行；不同節點可並行（key 含 nodeId）
操作成功Toast「web-server-01 nginx.service 已重啟」（success）狀態列更新（WS 同步，無需重整）
操作失敗Toast「web-server-01 nginx.service 重啟失敗：權限不足」（error）按鈕恢復可重試
操作逾時（15s）Toast「web-server-01 操作逾時：nginx.service restart」（warning）按鈕恢復可重試
切換節點NodeSwitcher 下拉（狀態燈清單 + active 反白）選取 → ?node={id}；URL 同步
返回 Aggregate「← 所有節點」連結→ /（NodeSwitcher 亦提供「所有節點」選項）
?service= 初始展開目標服務列自動展開 LogDrawer搜尋結果跳轉情境（BDD @search）
無障礙：離線 Banner role="alert"（即時朗讀）；禁用按鈕 disabled 語意完整（非僅顏色）；NodeSwitcher radiogroup 語意 + 方向鍵操作。
