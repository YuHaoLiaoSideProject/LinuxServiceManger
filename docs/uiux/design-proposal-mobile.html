📱 Key UX Improvements

  • Bigger touch targets: All interactive elements ≥ 48px per WCAG 2.5.5 (up from 40px)
  • Larger text: 16px body font (up from 13px) for comfortable reading at arm's length
  • Clear visual hierarchy: Service name is prominent, status is color-coded, meta info is de-emphasized
  • Primary action distinction: The most likely action (Start/Stop) is a full-width colored button; secondary actions (Restart, Logs) are icon buttons
  • Sticky quick bar: "Restart All" is always one tap away at the bottom
  • Pulsing status dot: Active services have a subtle pulse animation for glanceable status
  • Auto-start toggle: Clean iOS-style toggle with clear label
  • Locked services: Left border accent + reduced opacity distinguish system services
  • Horizontal stats: Swipeable stat chips save vertical space
  • Dark mode: Full dark mode support via CSS variables
