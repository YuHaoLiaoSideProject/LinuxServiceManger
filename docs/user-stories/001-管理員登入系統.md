# 001 — 管理員登入系統

**User Story：**
> As a 團隊管理員，
> I want 使用帳號密碼登入服務管理系統，
> So that 只有授權人員才能操作 Linux 服務，避免未授權的啟停操作。

**驗收條件：**
1. **Given** 使用者未登入，**When** 造訪任意頁面，**Then** 強制跳轉至登入頁面
2. **Given** 使用者輸入正確的帳號密碼，**When** 點擊登入，**Then** 跳轉至服務列表頁，並顯示登入成功提示
3. **Given** 使用者輸入錯誤的帳號密碼，**When** 點擊登入，**Then** 停留在登入頁，顯示「帳號或密碼錯誤」提示
4. **Given** 使用者已登入且閒置超過 30 分鐘，**When** 嘗試操作任何服務，**Then** 自動登出，重新導向登入頁
5. **Given** 使用者已登入，**When** 點擊登出，**Then** 清除 session，跳轉至登入頁

**邊界案例：**
- 連續 5 次登入失敗後，鎖定該帳號 15 分鐘
- 多人同時使用同一帳號登入，各自 session 獨立不互相踢出

**優先級：** Must

**複雜度：** S
