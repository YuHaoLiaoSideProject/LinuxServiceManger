# 001 — 管理員登入系統

**User Story：**
> As a 團隊管理員，
> I want 使用帳號密碼透過 JSON API 登入服務管理系統，
> So that 只有授權人員才能操作 Linux 服務，避免未授權的啟停操作。

**驗收條件：**
1. **Given** 使用者未登入，**When** 造訪任意頁面，**Then** 前端路由強制跳轉至 `/login` 登入頁面
2. **Given** 使用者輸入正確的帳號密碼，**When** 送出登入表單，**Then** 前端呼叫 `POST /api/v1/login`（form-urlencoded），收到 JSON 成功回應後跳轉至服務列表頁，並顯示登入成功提示
3. **Given** 使用者輸入錯誤的帳號密碼，**When** 送出登入表單，**Then** API 回傳 401 `{"error": "invalid credentials"}`，前端停留在登入頁，顯示「帳號或密碼錯誤」提示
4. **Given** 使用者已登入且閒置超過 30 分鐘，**When** 嘗試呼叫任何受保護的 API，**Then** API 回傳 401 `{"error": "unauthorized"}`，前端自動導向登入頁
5. **Given** 使用者已登入，**When** 點擊登出按鈕，**Then** 前端呼叫 `POST /api/v1/logout` 清除 session，跳轉至登入頁
6. **Given** 使用者重新開啟頁面，**When** 前端初始化時呼叫 `GET /api/v1/session` 檢查既有 session，**Then** 若 session 仍有效則直接進入服務列表頁，無需重新登入
7. **Given** 使用者提交空白帳號或密碼，**When** 呼叫登入 API，**Then** API 回傳 400 `{"error": "username and password are required"}`

**邊界案例：**
- 多人同時使用同一帳號登入，各自 session 獨立不互相踢出
- 登入頁面支援 i18n 多語言切換（繁體中文 / English），依瀏覽器語言自動選擇預設語言

**非功能性需求：**
- Session 使用 HttpOnly Cookie 儲存，閒置 30 分鐘後自動失效，防止 XSS 竊取
- 登入頁面支援 RWD，在手機與桌面皆可正常操作
- 登入表單為 Vue 3 SPA 元件，透過 axios 呼叫 `/api/v1/login`，非傳統 HTML form 提交

**優先級：** Must

**複雜度：** S
